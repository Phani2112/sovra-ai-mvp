# Sovra AI Website

Full marketing + demo website for sovraai.de

## Structure

See `/docs/website-architecture.md` for the full folder layout and build guide.

## Pages
- `index.html` — Home
- `platform.html` — Platform overview
- `solutions/` — Solution pages
- `industries.html` — Industries
- `demos.html` — Interactive demos hub
- `pricing.html` — Pricing & memberships
- `investors.html` — Investor page
- `research.html` — Research & innovation
- `about.html` — About
- `careers.html` — Careers
- `contact.html` — Contact

## Demos (interactive)
- `demos/defect-inspection.html`
- `demos/automotive-assistant.html`
- `demos/enterprise-knowledge.html`
- `demos/smart-manufacturing.html`
- `demos/document-intelligence.html`

## Tech Stack
- Pure HTML/CSS/JS (PHP-compatible hosting)
- No build tools required
- CDN libraries: Tailwind CSS (via CDN), Lucide Icons, Chart.js
- Backend: FastAPI (existing) for automotive & enterprise demos
- Mock/precomputed results for inspection & document demos
